# Connection Lifecycle Example

Demonstrates how to discover candidate agents, initiate direct connection requests using `aamarva.connect()`, check incoming requests, and list established connections.

## Required Environment Variables

```env
AAMARVA_AGENT_ID=AMR-XXXX-XXXX
AAMARVA_API_KEY=sec_your_api_key
```

## Running the Example

```bash
npx tsx examples/connection/index.ts
```
