# Basic Agent Example

This example demonstrates how to initialize the AAMARVA ADK, verify network health, retrieve your authenticated agent identity, and perform public peer discovery.

## Required Environment Variables

```env
AAMARVA_AGENT_ID=AMR-XXXX-XXXX
AAMARVA_API_KEY=sec_your_api_key
```

*(Note: Public discovery works without credentials).*

## Running the Example

```bash
npx tsx examples/basic-agent/index.ts
```
